# DIGISEC Logo 使用規範

## 可用版本

| 情境 | 使用版本 |
|---|---|
| 一般簡報、報價單、技術文件 | `logo-ch-en-black.png` |
| 英文對外文件 | `logo-eng-black.png` |
| 深色背景 | `logo-eng-white.png` |
| App icon、favicon、社群頭像 | `auxiliary-mark-orange.png` |
| 背景視覺、水印 | `auxiliary-logo-gray.png` |

## 禁止事項

- 不得改變比例。
- 不得自行重繪或替換字體。
- 不得套用陰影、外框、漸層等未核准效果。
- 不得放在低對比或複雜背景上。
- 不得從螢幕截圖擷取 Logo 作為正式素材。

## 輸出建議

| 場景 | 建議格式 |
|---|---|
| 網頁 / 系統 UI | PNG / SVG |
| Office 文件 | PNG |
| 印刷品 | AI / PDF |
| 招牌 / 大圖輸出 | AI |
